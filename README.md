# mbo-ga

A fresh farm produce marketplace built with React Native and Expo SDK 57.

## Run locally

1. Install Node.js 22.13 or newer.
2. Run `npm install`.
3. Run `npm start`, then scan the QR code with Expo Go or open an emulator.

The current build includes onboarding, lightweight sign-in, produce search and filters, a working basket, quantity controls, and checkout confirmation. Product and account data are currently demo data stored in memory.
